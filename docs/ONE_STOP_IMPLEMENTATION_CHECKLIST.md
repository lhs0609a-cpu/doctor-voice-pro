# 원스톱 자동화 구현 체크리스트

기준 커밋: `6659fa6`

## 연결된 기능

- [x] 고객사별 규칙 저장 및 원고 명령어 반영
- [x] Gemini 2.5 Flash 기본 모델 및 사용량 표시
- [x] 블로그 ID 분석 API와 블로그 지수 저장
- [x] 검색량·경쟁도 조회
- [x] 키워드 100·200·300개 선택 및 배치 판정
- [x] 상위 노출 글·실제 블로그 순위 판정
- [x] 원고 생성·이미지 계획·GIF 처리
- [x] 캠페인 예약 발행 파이프라인
- [x] 로컬 Playwright 에이전트의 로그인·계정 확인·원고 입력·이미지 업로드·예약 발행
- [x] 발행 성공 후 네이버 검색 화면 PNG 캡처 전송
- [x] 검색 URL·검색 시각·순위·캡처 경로를 작업 증거로 저장

## 검증 방법

1. 로컬 에이전트를 `publish-agent`에서 실행합니다.
2. 네이버 계정 연결과 블로그 ID 대조가 성공해야 합니다.
3. 원스톱 화면에서 키워드 수를 100/200/300개 중 선택합니다.
4. 캠페인을 시작하면 원고·이미지·예약 발행 작업이 서버 작업 큐에 생성됩니다.
5. 에이전트가 예약 발행을 완료하면 해당 키워드 검색과 캡처가 실행됩니다.
6. 원스톱 작업 목록에서 검색 URL과 순위가 표시되는지 확인합니다.

## 운영 조건

- 로컬 에이전트에 Playwright와 Chromium이 설치되어 있어야 합니다.
- 에이전트가 네이버에 로그인된 persistent profile을 사용해야 합니다.
- 네이버 검색 결과는 로그인 상태·노출 지역·시점에 따라 달라질 수 있습니다.
- 캡처 파일은 백엔드 `/data/verification`에 저장됩니다.
